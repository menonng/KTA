# 패러디 브랜드 목록 (Brand Bible)

> 작성일 2026-11-27 · 계획서 7장의 상세 목록입니다.
> **디자인 수준: A(사용자 결정).** 로고 형태, 배색, 간판 레이아웃, 매장 인테리어, 실제 매장 위치는 실제 브랜드를 따르고 **이름만 패러디**로 바꿉니다. 상표 유사·부정경쟁 위험을 인지한 상태로 진행하며, 공개 범위를 넓힐 때 다시 검토합니다.

## 3. 국가기관·공공 명칭

정부 상징을 허락 없이 상업적으로 쓰면 부정경쟁방지법에 따라 형사처벌 대상이 될 수 있다고 특허청이 경고한 바 있습니다(2019). 그래서 국가기관이 나오는 장면(예: 레퍼런스의 출입국·외국인청 건물)은 아래처럼 처리합니다.

| 요소 | 처리 | 예시 |
|---|---|---|
| **정부 상징(태극 마크), 부처 로고** | **쓰지 않습니다.** 모양과 배색이 다른 가상 정부 문양으로 대체 | 태극 대신 원형 안에 물결 세 줄이 있는 가상 문양 |

## 3.5 간판 표기 규칙 (2026-11-27 추가)

**원본이 외국어 간판인 곳은 그 양식을 따릅니다.**

- **외국 브랜드:** 실제 매장 간판이 영문 로고인 브랜드는 패러디 이름도 영문으로 씁니다. 한글 패러디 이름은 내부 이름으로만 씁니다.

  | 올리브올드 | OLIVE OLD | 영문 로고 |
  | 다사소 | DASASO (+작은 한글 다사소) | 영문 + 한글 |
  | 라떼리아 | LATTERIA | 영문 로고 |
  | 라떼시네마 | LATTE CINEMA | 영문 로고 |
  | 기가박스 | GIGABOX | 영문 로고 |
  | 기가커피 | GIGA COFFEE | 영문 로고 |
  | 심송 | SIMSONG | 영문 로고 |

- **외국 음식점:** 일식은 일본어(居酒屋, ラーメン, とんかつ) 아래에 작은 한글 표기를 넣습니다. 노렌풍 남색 판, 원목 판, 붓글씨를 씁니다.
- **중식(한국식 중화요리):** 한글 상호에 한자 상호(北京飯店 등)를 함께 씁니다. 빨강·노랑 판에 금색 띠를 두릅니다.
- **마라탕·양꼬치:** 간체자(麻辣烫, 羊肉串)를 크게, 한글을 작게 씁니다.
- **베트남·태국·이탈리아·프랑스·멕시코:** 그 나라 글자와 색(Phở, ครัวไทย, Trattoria, Boulangerie, Taquería)을 씁니다.
- **동네 가게 상호:** 실제 상호는 쓰지 않습니다. 한국에서 흔한 작명 방식으로 만듭니다.
  - 지역+음식: 의정부부대찌개, 마산아구찜
  - 사람+음식: 할매순대국, 이가네튀김
  - 영어 단어의 한글 표기+업종: 럭키코인노래방, 블룸헤어
  - 동네+수식어+진료과: 홍대바른정형외과
- **'포차' 같은 특정 업종:** 실제 분포보다 많아 보이지 않게 비중을 낮게 둡니다.
